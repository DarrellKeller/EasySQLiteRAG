# EasySQLiteRAG

Turn your data into a local app with cited AI answers, keyword/semantic search and an interactive map. No Docker or example data.

Paste this into your AI coding agent:

```text
Get https://github.com/DarrellKeller/EasySQLiteRAG and follow skills/easy-rag/SKILL.md to set up and launch this app with my data.
```

The agent will download the app, ask where your data is, set up the local models and open your app. You do not need to download the repo or run commands yourself.

The default models run locally; your coding agent may use its own cloud provider.
