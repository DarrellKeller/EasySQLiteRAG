# EasySQLiteRAG

Turn your data into a local app with cited AI answers, keyword/semantic search and an interactive map. No Docker or example data.

Download or clone this repo, open the folder in your AI coding agent, and paste:

```text
Follow skills/easy-rag/SKILL.md to set up and launch this app with my data.
```

Put your files in `documents/`, or tell the agent where they are. It will ask a few questions, set up the tools and local models, process your data, flag missing content and open the app. No programming knowledge needed.

The default models run locally; your coding agent may use its own cloud provider.
